TERRA / 05 DIRECTIONS

Recursion icons

不是抽象無限符號；每一個方向都把「多個 agent 在可見回合內共同推進」變成可讀的圖形。

01 / RELAY

接棒的回合

兩個不閉合的循環與箭頭，中心節點是正在被推進的共同任務。適合產品主 icon。

02 / NESTED

巢狀對話

兩個互扣的對話框：一段對話在另一段對話中再產生新脈絡。最直接讀作 recursion。

03 / TRIAD

三個聲音

三位 participant 形成穩定迴路；中心的加號表達合成，而不是投票式的平均。

04 / FORK & RETURN

分岔後歸來

同一個起點分成兩條可追溯的推理路徑，再帶著結果回到主線。最有工程感。

05 / DEPTH

遞迴深度

同形狀向內自我呼叫，保有六角輪廓的硬朗與系統感；在 16px 也可縮成中心六角。

建議：先拿 01 Relay 做 favicon、app tile 與 loading motion；02 Nested 最適合品牌名稱旁的靜態識別。
