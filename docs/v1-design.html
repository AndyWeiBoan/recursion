讓人和多個 coding agent 在同一個房間裡工作

一頁看懂

名字取自 AI 精神病圈的黑話「recursion」：人跟 AI 越聊越深、互相附和停不下來。agent 互相 @ 的時候，也正好就是遞迴。

做成什麼桌面 app，全 Rust，不帶 Node
接哪些 agentClaude、Codex，直接用你已登入的 CLI
版面像 tmux：Session、Window、Panel
Panel 種類群聊、終端、瀏覽器
群聊沒 @ 就發給全部 agent；agent 之間只有 @ 才觸發
回覆形式文字、表格，加上可以操作的 HTML
背景常駐關掉視窗，agent 照樣在跑
安全作業系統沙箱，超出專案資料夾要你同意

畫面長這樣

外觀參考 Rex。左側是依專案分組的 session；上方是這個 session 的 window 分頁；每個 window 裡用 panel 自由分割。下面這個 window 分成三個 panel：群聊、你的終端、正在預覽的網頁。

  • 1Claude 的回覆裡有一張表，第一列掛著 💬 2，代表那裡有一個討論串。下面是一個可以直接選的小表單。
  • 2Claude 用 @cx 把問題丟給 Codex，Codex 就會被觸發。
  • 3Codex 要在背景跑測試，先跳出核准卡片；結果會以 ⎿ 摘要顯示在這裡，不會佔用你的終端。

版面：Session、Window、Panel

結構照 tmux。熟 tmux 的人一看就懂，不熟的人也只要記得「一個專案、幾個分頁、每頁切成幾塊」。

Session一個專案。決定工作目錄、沙箱範圍、你允許過的路徑。左側列表的每一項就是一個 session。
Windowsession 裡的分頁，每個分頁有自己的分割版面，例如「重構」、「壓測」各一個。
Panel分割出來的每一塊，有三種，下面說明。
workspace

群聊

一個獨立的群聊，有自己的 agent 成員和對話紀錄。同一個專案可以開好幾個，各聊各的。討論串收在它右側的抽屜裡。

terminal

終端

給你用的終端。agent 不會開、也不會碰它；agent 要跑指令是在自己的背景執行。

browser

瀏覽器

開任意網站或本機 HTML。agent 想給你看一個比較大的頁面時，也會開一個這種 panel。

關掉視窗就像 tmux 的 detach：agent 和終端在背景繼續跑，重開 app 自動接回原本的版面。

快捷鍵

分三層，不同習慣的人各取所需。不想記任何按鍵的人，所有操作都能用滑鼠或指令面板完成。

給所有人

一般 app 快捷鍵

  • macOS：⌘T 新 window、⌘D 分割、⌘W 關閉、⌘1–⌘9 切 window、⌘K 指令面板
  • Linux：同樣的功能改用 Ctrl+Shift，跟一般終端軟體的習慣一致
  • 這些按鍵不會送進終端，跟 shell、vim 都不衝突
給 tmux 使用者

Prefix 模式

  • 預設 Ctrl+;：終端程式本來就收不到這個組合，所以 shell、vim、tmux 都沒在用；也不會撞到 macOS 用 Ctrl+Space 切輸入法
  • 按下後在畫面下方跳出提示，不用背
  • 不想按組合鍵的人可以改成「單按右 ⌘」
給 vim 使用者

nvim 式導航

  • Ctrl+H J K L 直接在 panel 之間移動
  • 終端裡正在跑 nvim 時，這組按鍵交給 nvim；要離開就按 Ctrl+; 再按 h j k l
  • 群聊裡按 Esc 離開輸入框，j k 在訊息區塊間移動，Enter 開討論串，/ 搜尋，i 回到輸入框
  • 終端的捲動複製模式用 vim 按鍵

架構

分成兩個程式：常駐背景的 recursiond 負責所有事情，桌面 app 只是看它、操作它的畫面。最下面是實際做事的 agent 和瀏覽器引擎，都是你電腦上本來就有的東西。

技術細節：agent 怎麼被驅動

Claude：claude -p --input-format stream-json --output-format stream-json。用 --resume 續聊、--fork-session 開討論串、--append-system-prompt 告訴它群聊規則、--mcp-config 掛上我們的工具、--permission-prompt-tool 把權限詢問接到我們的核准卡片。

Codex：codex app-server，用 JSON-RPC 溝通，可以中途要求核准，用 thread/fork 開討論串。官方仍標示為實驗性質。

兩個 CLI 都是使用者自己安裝和登入，app 不另外打包，所以 app 本身大約 10–20 MB。

群聊規則

  • 你的訊息有 @ 就只給被 @ 的人，沒有 @ 就給這個群聊的所有 agent。
  • agent 的訊息只有 @ 到誰，才會叫醒誰。
  • 每個 agent 都看得到大家說的話，但看不到別人在背景讀了什麼檔、跑了什麼指令。
  • 可以替 agent 取別名，例如把 Codex 叫做 @cx。

怎麼避免 agent 互相 @ 停不下來

每串最多 10 輪從你發的一則訊息算起，agent 之間最多來回 10 次。你再發話才重新計算。
同兩個 agent 最多來回 4 次避免兩個 agent 一直互相說「好的，你說得對」。
沒話說可以不說agent 回 [PASS] 就不會出現在畫面上。
重複就暫停同一個 agent 連續 3 次說幾乎一樣的話，自動停下來。
隨時全部停止按 Esc 或停止鈕，所有 agent 立刻停。

超過上限時會問你「要再給 10 輪嗎？」，不會默默繼續花錢。

HTML 回覆

agent 想給你一張表單、一個畫面草稿或一張圖表時，呼叫一個工具把 HTML 交給我們，畫面就直接出現在對話裡。這是參考 claude.ai 的內嵌元件和 MCP Apps 標準的做法。

show_widget

在對話中顯示。agent 可以選擇停下來等你填完，填好的資料直接回到它手上。

open_pane

比較大的頁面，開成一個新的瀏覽器 panel。

畫面放在隔離的 iframe 裡執行。v2 有遠端使用者後，別人的 agent 產生的 HTML 也會在你的 app 裡跑，所以一定要隔離。
技術細節：小畫面能用的 API 
recursion.reply(data)      // 回給叫出這個畫面的 agent
recursion.sendPrompt(text) // 當作你在群聊裡打字
recursion.ask(text)        // 對畫面裡選取的內容開討論串
// 一般的 <form> 送出會自動變成 reply(表單資料)

另外有 read_me 工具，agent 需要時才載入設計規範（配色、元件寫法、能用的 CDN），不必每次都塞進提示詞。畫面一邊產生一邊顯示，<script> 等內容完整才執行。

權限與沙箱

以 session 的專案資料夾為界，由作業系統強制執行（macOS 用 Seatbelt，Linux 用 bubblewrap），不是只靠 agent 自律。

情況會發生什麼
在專案資料夾內讀寫直接允許
碰到資料夾外先被系統擋下，agent 提出申請，跳出系統對話框讓你決定
agent 要跑指令跳出核准卡片，可以勾「以後都允許這個指令」；指令在背景執行，結果顯示在對話裡
你自己的終端不受限制，agent 也碰不到

瀏覽器

給你看的

瀏覽器 panel 直接用系統內建的瀏覽器引擎，任何網站都能開，也能登入。

給 agent 用的

同一個引擎，在背景開一個看不見的分頁。agent 可以讀網頁、點擊、填表、截圖，而且跟你共用登入狀態。

agent 在瀏覽什麼會顯示在對話裡，點一下就能在瀏覽器 panel 打開同一頁。之後再評估要不要自己做一個更輕量的 agent 專用瀏覽器。

討論串

回覆很長的時候，可以對某一句、某一列直接追問，不會打亂主對話。討論串屬於它所在的群聊 panel，收在 panel 右側的抽屜裡。

  • 預設由寫那句話的 agent 回答，也可以 @ 其他人進來。討論串不會發給所有人，其他 agent 也看不到。
  • 按「↩ 帶回主對話」，agent 會把結論濃縮成一句貼回主線。
  • 完成：問完但想留紀錄，討論串會收到列表底部變灰，徽章變淡。
  • 刪除：不跳確認，底部出現「已刪除［復原］」，幾秒內可以救回。已經帶回主對話的摘要會保留。
  • 抽屜可以收到右邊，只留一條細邊欄顯示數量；有沒看過的回覆會亮一個小點。panel 太窄時抽屜改成蓋在對話上。
  • 快捷鍵：Ctrl+; 再按 t 開關抽屜；抽屜裡 j k 移動、Enter 打開、h 返回、dd 刪除。

開發順序

M0骨架recursiond 與桌面 app、Session／Window／Panel、存檔、detach。能分割版面；關掉 app 再開，版面還在。
M1跟一個 Claude 對話群聊 panel、串流顯示、權限卡片、續聊。能正常對話並改檔。
M2終端與快捷鍵終端 panel、三層快捷鍵、提示面板、Ctrl+HJKL 導航、捲動複製模式。不碰滑鼠就能開、分割、切換 panel。
M3HTML 回覆工具伺服器、隔離顯示、資料回傳。agent 丟出表單，填完資料回到 agent。
M4多 agent 群聊接上 Codex、別名、@、群發、防遞迴、多個群聊。Claude 和 Codex 能互相 @，也會自己停。
M5作業系統沙箱沙箱設定、存取申請對話框、指令核准與記憶。資料夾外的存取需要你同意。
M6瀏覽器瀏覽器 panel、agent 的背景瀏覽器。agent 能讀網頁和截圖；你能開任意網站。
M7討論串句子定位與徽章、抽屜列表與內容、完成與刪除、分支、帶回主對話。能對表格某一列開串並帶回結論。
M8Linux 與安裝檔Linux 驗證、自動產出安裝檔。兩個平台都能安裝執行。

風險

CLI 協定可能變

兩個 CLI 的程式介面文件不多，升版可能要跟著改。把驅動層隔開，並固定版本跑測試。

Linux 上的瀏覽器 panel

Tauri 的多 WebView 還不穩定，Linux 最容易出問題。M6 先驗證，不行就改成獨立視窗。

兩套平台程式碼

背景瀏覽器要直接呼叫 macOS 和 Linux 各自的 API。包成同一個介面，各寫一份實作。

token 花費

群發加上多個 agent 很快就貴。靠 [PASS]、輪數上限、只送新訊息和快取來控制。
